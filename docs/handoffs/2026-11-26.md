## Set up a fresh machine

Use Git, Node.js 24 and npm, with GitHub access to Reborn and PlayBridge. The submodule commands show the commit recorded by Reborn and the checked-out framework commit. They should agree. The PM verified both pins, clean installs, tests and both production builds in a fresh recursive GitHub clone using Node 24.11.1.

~~~sh
git clone --recurse-submodules https://github.com/mcorcosa/master-of-donuts-2-reborn.git
cd master-of-donuts-2-reborn
git submodule update --init --recursive
git rev-parse HEAD
git ls-tree HEAD -- vendor/playbridge
git -C vendor/playbridge rev-parse HEAD
npm --prefix vendor/playbridge ci --include=dev
npm --prefix vendor/playbridge run build
npm --prefix vendor/playbridge test
npm ci
npm test
npm run typecheck
npm run build
npm run build:facebook
~~~

Run `npm run dev -- --port 8091 --strictPort` from the Reborn root and open `http://127.0.0.1:8091/`. Check the Vanilla Bean mascot and the Pixi gameplay menu to confirm the right game is running. The production outputs are `dist/` for web and `dist-facebook/` for Facebook.
